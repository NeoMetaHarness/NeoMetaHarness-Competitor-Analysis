# Competitor profile

## Record
Name, product category, primary audience, URLs for public documentation/pricing, observed date and supported platforms.

## Comparison
| Dimension | What to verify |
| --- | --- |
| Extension model | Packaging, lifecycle and isolation |
| Automation | Human approval, schedules and retries |
| Portability | Data export, self-hosting, dependencies |
| Pricing | Public plan price and limits at observation time |
| UX | Onboarding steps and documented accessibility |

## Evidence
Cite first-party docs where possible. Label tests as observations. Unknown is acceptable. Avoid scraping protected user data or representing an assumption as a fact.
